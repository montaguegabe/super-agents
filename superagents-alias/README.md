# superagents

This is an alias distribution for [`super-agents`](https://pypi.org/project/super-agents/).

Installing `superagents` installs `super-agents`. The Python import name is
`super_agents` in both cases (though `import superagents` also works via a
forwarding module).

`superagents` is planned to become the canonical distribution name; at that
point `super-agents` will become the alias. Either name will continue to work.

See the [project repository](https://github.com/montaguegabe/super-agents) for
documentation.
